# 📝 Ishlist 

**Capture ideas, manage tasks, and organize your mind—all in one place-ish.**

Ishlist is a modern, high-performance note-taking application designed with a focus on clean UI and seamless data persistence. Built using **React** and **Supabase**, it features a public community board interface where anyone can contribute and manage thoughts instantly.

[🚀 View Live Demo](https://ishlist-307.netlify.app/)

---

## ✨ Features

* **Public Bulletin Interface:** No login friction—just open and start writing.
* **Dynamic Categorization:** Tag your notes as "Idea-ish," "work-ish," or "personal-ish."
* **Real-Time Persistence:** Powered by Supabase for instantaneous database updates.
* **Modern Glassmorphism:** A sleek UI featuring Tailwind CSS backdrop blurs and smooth transitions.
* **Full CRUD Functionality:** Create, Read, and Delete notes with zero latency.

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React.js (Context API) |
| **Styling** | Tailwind CSS |
| **Backend** | Supabase (PostgreSQL) |
| **Deployment** | Netlify |
